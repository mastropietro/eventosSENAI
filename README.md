As funções deverão ser executadas separadamente por cada membro.



Nichollas (gerente) - Listar os eventos, criar links para detalhes, edição e remoção e oferecer acesso ao cadastro. Nos detalhes, mostrar todos os campos do evento. Tratar lista vazia e ID inexistente. Deverá criar uma branch de nome index-e-detalhes e desenvolver sua parte por ela.





Lennon - Exibir o formulário, validar os campos e cadastrar o evento na sessão com ID único. Após salvar, redirecionar

para index.php. Deverá criar uma branch de nome formularioCadastroEvento e desenvolver sua parte por ela.



Pedro - Receber o ID, carregar os dados no formulário e salvar as alterações mantendo o mesmo ID. Tratar ID

inexistente e redirecionar para index.php após salvar. Deverá criar uma branch de nome formularioEdicaoEvento e desenvolver sua parte por ela.



Rafaela - Receber o ID, mostrar o evento e pedir confirmação. Oferecer a opção de cancelar. Remover somente após

confirmação por POST e voltar para index.php. Tratar ID inexistente. Deverá criar uma branch de nome formularioRemocaoEvento e desenvolver sua parte por ela.
